## 背景与上下文
`AnsiParser.feed` 是 loguru 着色器解析 ANSI 风格标签的核心循环。它负责扫描文本中的 `<tag>` 标记，将普通文本和颜色指令转换为 token 流，同时维护标签栈以支持嵌套和错误检测。当前实现将所有逻辑塞在一个 42 行、圈复杂度高达 13 的方法中，转义处理、标签解析、关闭逻辑和 token 生成混杂在一起，难以阅读和测试。需要在不改变任何对外行为的前提下，通过提取模块级辅助函数来分解职责、降低复杂度。

## 输入
- `text: str`：待解析的字符串，可能包含颜色标签（如 `<red>`、`</red>`）以及用于转义的反斜杠。
- `raw: bool = False`：关键字参数，若为 `True`，则直接将整个 `text` 作为普通文本 token 追加并返回，不进行任何标签解析。

## 输出
- 方法没有返回值（`None`），其副作用是向 `self._tokens` 追加解析出的 token 序列，并可能更新 `self._tags` 和 `self._color_tokens` 栈。
- 异常语义：当遇到未闭合标签、嵌套错误或未知标签时，必须抛出与原实现完全相同的 `ValueError`，错误消息逐字一致。
